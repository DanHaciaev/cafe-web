# Cafe Print Agent

Небольшая программа, которую нужно один раз установить на компьютер кассы —
туда, где физически подключён термопринтер **TP805L** и (опционально)
банковский терминал. Она печатает кухонные чеки и запускает оплату картой,
пока сам сайт (cafe-web) может быть развёрнут где угодно — хоть на Vercel —
потому что у облачного сервера нет доступа к оборудованию, стоящему в кафе.

Сайт стучится в `http://127.0.0.1:47991`, где слушает этот агент. Если агент
не запущен — печать чека и оплата картой недоступны: сайт откроет страницу
чека в новой вкладке для ручной печати, а кнопка «Charge» примет только
наличные.

## Установка на кассовый ПК (без Node.js — просто .exe)

Установщик уже собран, Node.js на кассе ставить не нужно — только Chrome и
сам принтер/терминал.

1. Установите Google Chrome (агент использует его в headless-режиме, чтобы
   отрисовать HTML-чек перед печатью).
2. В Windows подключите принтер и назовите его в системе именно **TP805L**
   (Панель управления → Устройства и принтеры). Другое имя — поправьте
   `printerName` в `config.json` до установки.
3. Скопируйте на кассовый ПК всю папку `print-agent` целиком (или архив с
   ней) — важны файлы `install.bat`, `install.ps1`, `config.json` и папка
   `dist/cafe-print-agent.exe`.
4. Дважды кликните **`install.bat`**. Подтвердите запрос UAC (нужны права
   администратора, чтобы поставить автозапуск). Готово — агент уже работает
   и будет сам запускаться при каждом входе в Windows, без видимого окна.
5. Проверка: откройте `http://127.0.0.1:47991/health` в браузере на этом же
   ПК — должно быть `{"ok":true,...}`.

Если что-то пошло не так — сообщение об ошибке останется на экране после
установки, а подробности — в `%LOCALAPPDATA%\CafePrintAgent\agent.log`.

### allowedOrigins

В `config.json` (до установки — рядом с install.bat, либо после — прямо в
`%LOCALAPPDATA%\CafePrintAgent\config.json`) должен быть перечислен адрес
вашего сайта, иначе агент откажется печатать/принимать оплату по запросу с
этого домена:

```json
"allowedOrigins": ["https://cafe.unisim-soft.site", "http://localhost:3000"]
```

## Банковские терминалы (опционально)

Кафе может иметь терминалы от разных банков одновременно — кассир выбирает,
через какой проводить оплату, прямо в окне «Оплата» на кассе. Настраиваются
на странице **`/admin/terminal`** сайта — но открыть эту страницу нужно **на
самой кассе** (браузер обращается к локальному агенту напрямую, а не через
сайт), там указываете для каждого терминала банк/драйвер и порт.

Поддерживаемые драйверы:

- **MAIB (Arcus2)** — терминал подключён по COM-порту. Требует:
  - 32-битный Python, установленный с [python.org](https://www.python.org/downloads/)
    (не из Microsoft Store — там нет алиаса `py -3-32`, который использует агент).
  - Папку `maib-bridge/` рядом с `.exe` (устанавливается автоматически вместе
    с install.bat, если она была рядом с install.ps1 при установке).
  - Укажите реальный COM-порт терминала в настройках на `/admin/terminal`.
- **VB / MICB / FCB** (Victoriabank / Moldindconbank / Fincombank) —
  терминал подключается по Wi-Fi/Ethernet к этому ПК напрямую. Никакого IP
  указывать не нужно — только порт, тот же самый нужно прописать в настройках
  меню самого терминала («подключиться к кассе по IP:порт»).

Если ваш банк не входит в этот список — нужен реальный протокол/SDK этого
терминала, написать интеграцию «на всякий случай» без документации от банка
нельзя.

## Проверка печати

Оформите тестовый заказ на сайте — если агент настроен верно, чек уйдёт на
TP805L автоматически. Логи — в `%LOCALAPPDATA%\CafePrintAgent\agent.log`.

## Важно

- Агент слушает только `127.0.0.1` — снаружи этого компьютера к нему
  обратиться нельзя.
- Каждый запрос проверяется по списку `allowedOrigins` — печатать и принимать
  оплату могут только вкладки, открытые с разрешённых адресов сайта.

## Разработка / пересборка .exe

Нужно только на компьютере разработчика, не на кассе:

```bash
cd print-agent
npm install
npm run build   # -> dist/cafe-print-agent.exe
```

`npm start` запускает агент как обычный Node-скрипт (`node agent.js`) —
удобно для отладки без пересборки exe при каждом изменении.
