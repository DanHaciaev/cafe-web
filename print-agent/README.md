# Cafe Print Agent

Небольшая программа, которую нужно один раз установить на компьютер кассы/кухни,
где физически подключён термопринтер **TP805L**. Она печатает кухонные чеки,
пока сайт (cafe-web) может быть развёрнут где угодно — хоть на Vercel — потому
что у облачного сервера нет доступа к принтеру, стоящему в кафе.

Сайт при оформлении заказа стучится в `http://127.0.0.1:47990`, где слушает
этот агент. Если агент не запущен — сайт откроет страницу чека в новой вкладке,
чтобы распечатать вручную через обычный диалог печати браузера.

## Установка (один раз, на ПК с принтером)

1. Установите [Node.js](https://nodejs.org) (LTS).
2. Установите Google Chrome (агент использует его в headless-режиме для рендера чека).
3. В Windows подключите принтер TP805L и убедитесь, что он называется в системе
   именно `TP805L` (Панель управления → Устройства и принтеры). Если название другое —
   поменяйте `printerName` в `config.json`.
4. В этой папке выполните:
   ```
   npm install
   ```
5. Проверьте `config.json`:
   - `printerName` — точное имя принтера в Windows.
   - `allowedOrigins` — добавьте туда адрес вашего сайта (например,
     `https://cafe.unisim-soft.site`), иначе агент откажется печатать по запросу с этого домена.
6. Запустите агент вручную для проверки:
   ```
   npm start
   ```
   Откройте `http://127.0.0.1:47990/health` в браузере на этом же ПК — должно
   вернуться `{"ok":true,...}`.
7. Чтобы агент запускался автоматически при входе в Windows (и работал в фоне,
   без открытого окна консоли), запустите от администратора:
   ```
   powershell -ExecutionPolicy Bypass -File install.ps1
   ```

## Проверка печати

Оформите тестовый заказ на сайте — если агент настроен верно, чек уйдёт на
TP805L автоматически. Логи агента — в файле `agent.log` рядом со скриптом.

## Важно

- Агент слушает только `127.0.0.1` — снаружи этого компьютера к нему обратиться нельзя.
- Каждый запрос на печать проверяется по списку `allowedOrigins` — печатать могут
  только вкладки, открытые с разрешённых адресов сайта.
